

# Admin Dashboard

A corporate-style admin panel with a login page, sidebar navigation, breadcrumbs, data tables, and a footer — all with a professional blue/gray color scheme.

## Pages & Features

### 1. Login Page
- Clean login form with email and password fields
- "Remember me" checkbox and "Forgot password" link (visual only)
- Submitting navigates to the dashboard (no real auth)
- Professional branding with a logo area

### 2. Dashboard Layout
- **Sidebar** with collapsible navigation using icons (Users, Products, Orders, Settings, etc.)
- **Top header bar** with breadcrumb trail, search input, and user avatar/menu
- **Footer** with copyright info and quick links

### 3. Dashboard Home
- Summary stat cards (Total Users, Revenue, Orders, Active Sessions)
- A recent activity table showing latest actions
- Clean card-based layout

### 4. Users Page (Table Example)
- Full data table with mock user data
- Columns: Name, Email, Role, Status, Date Joined
- Search/filter bar, pagination, and sortable columns
- Action buttons (View, Edit, Delete) per row

### 5. Settings Page
- Simple profile settings form (name, email, password change)
- Demonstrates form inputs and layout

## Design
- Corporate blue/gray color palette
- Consistent spacing, subtle borders, and shadow cards
- Lucide icons throughout for navigation and actions
- Responsive layout that works on desktop and tablet
